# 脱敏与公开包规则

把真实经验提炼为“触发条件、风险、必须动作、禁止动作、完成证据和匿名案例”，不要只替换几个项目名后复制原文。

## 不得进入公开包

- 密钥、令牌、私钥、证书、真实应用标识和认证配置。
- 用户主目录、真实仓库地址、内部域名、云环境和存储桶。
- 真实分支、提交、函数、集合、业务字段和后台状态。
- 未公开项目名、角色名、素材名、商业策略、价格和配额。
- 私有回归材料、真实截图和可还原项目身份的组合信息。

## 允许的匿名形式

- 项目路径写成 `/path/to/project`。
- 项目和业务使用完全虚构的学习、任务或商品示例。
- 函数和集合使用通用虚构名，例如 `submitResult`、`user_progress`。
- 示例分支和提交只展示格式，不使用真实值。

## 真实来源案例例外

默认不公开真实项目名、截图、二维码、角色素材或可组合还原项目身份的信息。只有在用户明确批准公开来源案例展示时，才可以保留展示名、公开截图或二维码；即使获准展示，也不得包含源码、AppID、云资源、私有配置、业务数据、审核状态、内部开发记录、真实分支、真实提交或后台证据。

来源案例只能说明方法来自真实小程序协作，不能作为该项目当前状态、平台审核、正式发布、源码开放或衍生 Skill 正确性的证据。需要验证 Skill 时，应继续使用匿名夹具、合成项目、隔离副本或无关授权项目。

## 出包门禁

- 只导出验证器声明的公共路径 allowlist；私有开发目录（`.planning`、`tests`、缓存和版本控制元数据）始终排除。
- 私有开发目录之外的未知文件默认拒绝，不因文件名看似无害、后缀陌生或扫描未命中而复制。
- allowlist 内所有候选都必须扫描，包括无后缀文件；二进制和非 UTF-8 候选必须进入扫描路径，不能静默跳过；真正无法读取的候选按失败处理。
- 运行 `python3 scripts/scan_sensitive_content.py <public-path> --format json`，逐项人工判断命中内容。扫描通过只能证明已覆盖规则未命中，不能代替人工匿名化复核。
- 使用 `python3 scripts/export_public_package.py <source> --output <new-directory>` 出包；若要公开新增文件，必须先经过审查并加入验证器的明确公共清单。
- 收到公共包后，在包外运行 `python3 <package>/scripts/verify_public_package.py <package>`；该入口不读取原始源码目录，并对 manifest、文件集合、大小和 SHA-256 进行复验。
- 包内一致性不能证明发布者真实性；若 payload 与 manifest 被同时重写，还必须对照可信渠道提供的包哈希或签名。
