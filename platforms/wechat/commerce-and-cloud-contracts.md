# 微信商品、云操作与事件核对合同

仅在项目使用对应能力时加载相应段落；不为补清单引入虚拟支付、云任务或订阅。本文是工程核对方法，不声明当前平台字段、按钮或 SDK 行为。时效性事实按 [平台规则治理](../README.md) 和当前官方一手资料核验，无法确认的部分保持 `unknown`。默认只读；导入、启用、部署、真实调用和交易分别受用户授权与预算约束。

## 虚拟道具导入与可见状态

先确认当前官方模板及真实后台接受格式；扩展名不证明实际格式，按文件签名、工作表、必需字段、类型和完整行数验证。输入价格与 API/签名价格分别写单位及转换依据，不把后台与接口单位视为天然相同。

按图片的实际访问主体验证 GET 状态、MIME、尺寸、体积及平台要求；确实由跨域页面访问时再核实际 Origin 和 CORS，不统一伪造一个 Origin。服务器能下载不证明目标平台页面能使用。模板未包含的关联属性在获准导入后逐件读回，数量相同不证明字段完整。

| 证据 | 可支持 | 不能推出 |
| --- | --- | --- |
| 文件格式、字段和单位预检 | 当前导入候选符合已核要求 | 已导入或发布 |
| 后台读回数量及关联属性 | 对应对象已存在且字段匹配 | 线上可见或支付可用 |
| 开发版/线上版各自列表 | 对应列表的可见状态 | API 同步、签名、付款或到账 |

上传、批量发布或提审按钮不是无副作用预检。具体文件限制、关联字段和商品状态按执行时证据维护，不复制来源项目常量。

## 云调用的信任边界

对严格业务白名单接口，从当前官方资料、目标 SDK 及去敏运行形状区分业务载荷、平台附加元数据、可信运行上下文。管理端空事件不能替代客户端输入形状。只在适配边界显式分离已核实的元数据，未知业务字段继续拒绝；不能按任意前缀剥离或整体放开白名单。

身份仅来自平台可信上下文及接口要求的会话校验；事件对象中的身份即使看似平台字段也不能授权。缺可信身份或身份不一致不能写入。SDK 形状变化保持未知并重新核验，不固定两个字段为所有版本的元数据列表。日志可留阶段、字段类别、业务/错误码、时间、耗时及脱敏的稳定业务关联标识、执行标识和 attempt ID，以支持关联与去重；不留完整事件、登录 code、身份或会话秘密，公开报告只保留安全引用。

## 配置更新、预检与异步终态

- 保存脱敏配置基线，更新后逐键读回启用门、空值、触发器和版本；省略环境变量不等于删除旧值。
- `dryRun`、`confirm` 等参数只是工具声明。副作用未核实前使用已确认的只读接口；发现创建副作用时停止该预检路径并核资源，不继续试探。
- Event ACK 只证明受理。按同一业务键关联 worker 终态、job/attempt、流水、结果及必要账户证据；重复事件须核不重复扣额或发权益。不能仅凭 HTTP 成功或无异常巡检判业务成功。
- 一次性持久操作与有时效观测分别记录。观测过期只刷新相关事实，不重做已确认初始化；新读取时间不能替换原事实截止时间。配置激活也不等于此刻获准业务写入。
- 自然调度、手动调用和平台回调分开。按有依据的执行标识关联去重，核触发来源、环境/版本、业务响应及持久结果；多行日志不能算多次执行，手动成功不能证明自然触发。
- 日志入口不可用时选择当前官方支持的只读来源；仍不可查则未核，不固化旁路接口。隔离故障演练、正式接线和正式故障触达分列；真实计费调用先固定样本与硬上限。

## 事件订阅的四层证据

核消息/事件类型、目标环境、目标处理函数与启用状态。创建后刷新读回，不能接受无关默认目标；按钮文案通常表达可执行动作，必须结合当前界面或状态字段判定，不跨版本机械套用菜单。

| 层 | 必需证据 | 不能替代 |
| --- | --- | --- |
| 已创建 | 当前订阅对象及字段 | 已启用 |
| 已启用且目标正确 | 刷新读回的状态与路由 | 真实送达 |
| 真实事件送达 | 绑定同一环境/版本/业务键的接收证据 | 业务完成 |
| 业务完成 | 处理终态和持久结果 | 新业务开放或正式发布 |

测试事件与真实事件分开；日志失败或事件表为空保持送达未核。启用接收不自动打开新增业务，关闭新增业务仍保留合同允许的存量善后。按 [云状态与写入合同](../../skills/mini-program-architecture-skill/references/cloud-state-and-write-contracts.md) 核恢复及回退。

## 最小验证与交接

原创场景覆盖伪装扩展名、异单位、缺关联、图片拒绝、开发有/线上无；正常/伪造元数据、未知业务字段、缺/冲突可信身份；ACK 后失败、残留配置、预检副作用、旧观测、重复日志、自然与手动差异；创建但禁用、错目标、日志不可查、送达后业务失败。

记录事实来源与核验日期、目标版本/环境指纹、每层最高证据、未核部分、下一项最小采集与副作用边界。合成场景只证明判定合同，不证明真实平台行为。
