# 资产谱系记录模板

用于记录图片、图标、动画、音频、字体及其他原始资产和衍生资产。每个实际文件或可独立批准的变体使用独立 `asset-id`；“看起来相同”不等于字节、透明通道、授权或目标槽位相同。

## 身份与来源

- `asset-id`：
- 资产类型：原始资产 / 衍生资产
- 文件名与相对路径：
- 来源：用户提供 / 自有素材 / 合法公共来源 / 生成 / 项目既有
- 来源标识或原始资产 `asset-id`：
- 许可、署名或使用限制：
- 原始文件 SHA-256：

## 衍生与处理

- 父资产 `asset-id`：
- 处理工具与工具版本：
- 处理方式：裁切 / 缩放 / 压缩 / 格式转换 / 抠图 / 调色 / 组合 / 其他
- 处理参数或可复现步骤：
- 输出格式：
- 尺寸（宽 × 高，单位）：
- 透明通道：有 / 无 / 未知
- 色彩空间或帧率等相关属性：
- 衍生文件 SHA-256：

## 使用与批准

- 目标页面与目标槽位：
- 目标状态、主题、机型或尺寸范围：
- 当前批准状态：`proposed` / `proposal-approved` / `implemented` / `unknown`
- 批准证据与时间：
- 批准范围：指定文件 / 变体 / 槽位 / 状态
- 替换关系：替换哪个 `asset-id`，或被哪个 `asset-id` 替换
- 旧资产保留、回滚或删除策略：
- 回滚入口：旧/新 `asset-id`、路径与哈希、目标槽位、当前引用、恢复条件和批准边界：
- 当前引用位置：

批准某个预览不等于批准其他尺寸、压缩版本、动画变体或目标槽位；记录替换关系不等于获得删除旧资产的授权。缺少哈希、透明通道、来源或批准范围时标记为 `unknown`，不能为了交接完整而猜测。

在正式替换完成、验证通过并具备可复查回滚入口前，默认保留旧资产；没有明确删除授权时不得删除。
只读评估也必须在交付输出中填写上述回滚入口；不需要、也不得为了“记录”而改动项目文件。

## 代表场景

用户批准一张角色透明 PNG 用于首页主槽位。记录原始图、抠图工具、尺寸、透明通道、原始与衍生哈希、批准证据和被替换的旧 `asset-id`，再进入正式集成。

## 边界场景

两个文件肉眼近似，但一个缺少透明通道且哈希不同。必须视为两个变体分别记录；在目标槽位和批准范围未确认前，不得把后者标记为已批准替换。
