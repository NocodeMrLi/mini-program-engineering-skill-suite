# 运行时解析状态、异步隔离与整页布局合同

## 返回刷新意图

余额、库存、权益、权限及跨页状态需刷新时，旧读仍在途不能丢失新读取意图。失效旧代次并保留一次有界补查，或采用能证明同等收敛的取消/版本机制；连续重显合并，旧成功、失败和清理不破坏新状态。卸载后不更新已销毁页面，不以客户端加减替代权威读。

驱动实际调用方：旧读等待→别页权威变化→返回→旧响应晚到→新读完成，断言查询确实发生且最终采用新值；另核旧失败、新失败、连续返回、卸载、正常单读。检索onShow/attempt ID不足以证明收敛，事件和队列留平台适配。

## 可中断展示与取消所有权

有退场弹层分别建模交互、视觉、资源：退出先停该层交互，视觉收尾后释放展示资源；重开接续当前可见状态并恢复新会话交互，旧通知/兜底不卸载新会话。通知缺失有有界收尾，静止后停止自驱动调度；卸载、系统立即隐藏或隐私要求优先即时清理。平台支持减少动态时静态/短过渡仍清理，不强制不存在的API，视觉完成不决定业务完成。

超时、权限变化、页面离开和上层取消须抵达当前操作的界面/资源所有者，幂等解除临时锁、禁用态、视觉反馈、点击抑制及所属资源，不依赖正常结束必达。非所有者卸载不取消新操作；展示取消不证明远端撤销，未知写入沿原标识恢复，取消路径零额外提交。

实际Page/Component方法核正常进出、退场重开/连续反向、旧/缺失结束通知、强制/重复取消、取消后重试、旧/当前实例卸载及适用减少动态。可控事件证明状态处理，视觉命中/遮挡/权限按目标运行时和真机另验，不用DOM或桌面窗口冒充小程序适配。

## 编辑保存的异步续作

有草稿/自动保存时捕获对象、会话、内容快照和代次；每个await返回后以及继续提交、更新状态或清草稿前核归属、有效性与输入确认。过期续作不发新提交、不清新内容；已发出的原对象写入按协议核结果，离开不等于撤销。成功仅确认/清理已保存代次，保存中新输入保留；失败/未知保留可恢复内容。

组合输入、失焦、强制flush、onHide/onUnload保证按目标框架/平台核；未确认输入不当最终内容，强制保存不绕过保护，不照搬DOM composition/桌面关闭协议，不承诺强退零丢失。逐个延迟边界执行实际调用方，核切对象/重开、新输入、旧成功/失败/清理、正常保存、输入确认和未知恢复的提交次数、写入对象/内容及当前提示。合成input/setData不等于物理输入法。

## 同轮保存的多入口收尾

完成、可等待导航与组件收尾要求同一对象/会话/编辑代次/完整内容的必要保存时，共同等待该次提交的同一成功或失败；前一次已成功、随后普通返回且内容与有效性未变，也复用该确认而不再写一次。串行队列/禁用按钮不等于合并，不能因busy忽略后调用却假称成功，也不用同一旧版本重复写。新输入、换对象、不同载荷或其他业务不错误复用。同一版本链上不同载荷须等待前次写入确认，再核归属、输入及已确认版本后单独提交；不能用尚未更新的预期版本并发写，也不能只加dirty标记却仍用旧返回覆盖新草稿。前次失败或结果未知时保留内容与真实状态，按协议查证或合规重试，不能把后续排队当作成功或绕过冲突。成功只确认已保存代次。归属、权限、版本、输入确认与未知恢复仍保留。

草稿自动保存和创建目录/确认关系等终态副作用分开，只有获准确认点才执行后者。产品允许时，输入停顿可持久化未确认名称等草稿字段以便恢复；禁止的是将它晋升为已创建实体或已确认关系，不能靠禁存草稿来消除终态副作用。字段名含“目录/集合”不证明发生实体创建，须追踪权威实体写入及实际消费者；产品明确支持自动创建则遵其规格。完成后立即返回是正常操作，程序负责等待及短反馈，不要求用户等几秒、强退或清缓存。不可等待的强制卸载按真实能力处理，再进入时基于持久证据展示未确认/失败及可恢复内容位置，不承诺强退零丢失。

验证延迟写下完成与导航交错、完成已成功后未编辑即返回、两调用方同结果/仅一次必要提交、草稿字段可恢复而未生成实体/确认关系、失败重试、新输入/切对象/异载荷、正常单入口及名称多段停顿。普通导航、真实卸载、合成输入、物理输入法分别取证。

## 前台尝试退出与业务未知

有远端异步受理和待核锁时分别核前台尝试、原持久业务、可信查询的当前观察。前台可退出/再次确认必须满足批准的失败分类、状态、可信查询及必要本地退出写入确认；一次未完成不等于永久未发生。成立时仅解除所属前台临时锁，不自动提交，原业务标识、保守占用、查证与晚到结果唯一处理保留。退出不授权换业务键重建未知业务；是否可创建独立新业务由规格及最终写入边界决定，新尝试未知也沿其原标识恢复。

未知/畸形结果、错归属、业务校验不符、状态冲突或退出写入未知不绕过；全局暂停、资格和权限等其他门禁不被局部退出解除。反馈在当前Page/Component可见层说明查询中、可再确认或待核及下一步。先区分结果未返回与已返回却被弹层遮住，不要求无限查询或切账户。实际调用方核按钮/提示，遮挡与命中按目标平台另验，层级数字或源码词不证明真机可见。

## 持久断点与隐藏等待

有跨重进恢复承诺时，选择已确认持久写之后、后续动作之前的必要断点，重新创建页面/组件并从同一持久源读回再接续；完成恢复后才重进不覆盖中途断点，JSON往返不证明生命周期恢复。隐藏/卸载后不能只等下一帧或假定后台计时继续来证明业务完成；按运行时用可观察确认、有界查询或重建读回，失败取证和清理也有界。对象已销毁不继续依赖它取图，不靠加超时或绕过保存保护变绿；不搬桌面API。

## 显式空值与展示派生

活跃输入绑定草稿，主动空字符串、缺字段、null、空白按领域分别解释，不以真假值统一回填默认。兜底只用于非编辑展示；成功保存更新持久基线，不以规范化响应/派生摘要重置输入或光标。产品明确提交时生成默认名称则保留该时点，不擅自删除合法提交政策。

字段组合由产品决定，创建/编辑/读取校验/备份恢复/退出保存沿同一有效性规则；非法组合保留最后成功数据及可恢复输入，不放宽类型、尺寸、权限、归属、并发和IO保护。核逐字清空、停过自动保存再输入、合法局部空值返回重开、非法整体空值、规范化响应、真实IO失败及旧值读取。schema/类型不变仍可能扩大值域：新合法数据进旧读取器须验，未兼容则保留独立升级前备份和降级边界，不让旧版覆盖唯一新数据。

## 解析状态

异步页面至少区分：

| 状态 | 允许显示 | 禁止推断 |
| --- | --- | --- |
| `unresolved` | 可信缓存、骨架或明确加载态 | 无数据、首次用户、零进度 |
| `resolved-empty` | 权威请求完成后的真实空态 | 请求仍在途或失败 |
| `resolved-with-data` | 已解析内容及其派生视图 | 数据已跨设备收敛 |

空数组、零值和默认对象不能单独决定空态；必须结合 `dataResolved`、`requestFinished` 或等价完成标记。冷启动、热启动、慢网和真实空数据分别验证。

## 可重入异步操作

短时提示、长按录音、上传、识别和可重复请求使用单调 attempt ID 或序号：

1. 每次新操作生成新 ID，并保存当前 ID。
2. 定时器、promise、事件回调和 stop 回调携带创建时 ID。
3. 回调写状态或停止资源前比较 ID；不匹配则只清理自身，不影响新操作。
4. 页面卸载或显式取消使当前 ID 失效，并释放与该次操作绑定的资源。

## 整页高度预算

复杂移动页在改布局前记录数值预算：

| 区域 | 高度来源 | 最小/最大值 | 是否固定 | 溢出策略 |
| --- | --- | --- | --- | --- |
| 顶部安全区/导航 | 系统信息或自定义导航 |  |  |  |
| 标题/tab | 内容和组件约束 |  |  |  |
| 核心内容 | 可用剩余空间 |  |  |  |
| 主操作 | 触控目标与文案 |  |  |  |
| 底部导航/安全区 | 系统与组件 |  |  |  |

修复任何局部后重新计算整页总量，确认主操作、底部导航和必要说明仍可见或可自然滚动。不能通过裁切、重叠或缩小触控区“满足”高度。

## 设备策略

设备差异判断按实际需要组合 system、model、brand、safe-area、viewport 和能力探测，不只依赖单一 `platform` 字段。记录采用信号、命中条件和回退；单一机型或截图不能证明策略通用。
