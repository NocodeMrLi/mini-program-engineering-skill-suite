# 云端状态、配置与写入安全合同

仅在项目涉及云端权威数据、持久化、第三方 SDK、多租户、一次性权益或外部计费服务时应用本合同；未触发的部分标记不适用，不为补表创造能力。

## 权威数据三态与恢复

- `unresolved`：尚未从可信缓存或权威源完成解析，不能展示“确认无数据”的流程。
- `confirmed-existing`：权威记录存在，进入正常路径并刷新可重建缓存。
- `confirmed-absent`：权威源明确确认不存在，才允许首次创建、领用或初始化。

本地无记录不等于云端不存在。创建返回“已存在/重复”时读取并采用持久化赢家结果，恢复缓存和正常路由。离线兜底必须有回写或对账路径，云端恢复后收敛到主数据。

## 配置组与真实依赖

- 对每组可选云能力列出必需变量、互斥 provider、默认禁用行为和校验时点。
- 整组缺失可以按已确认的未启用路径降级；只提供部分变量必须 fail-closed 并列出缺项。
- `.env.example` 只保留变量名和安全占位符，不放真实资源 ID、账号、地址或秘密。
- 导入目标、迁移集合/表、运行时依赖注入和 health 探测从同一配置源解析。
- health 分开报告进程存活与数据库、存储、队列等真实依赖可用性。

## 适配器边界与契约测试

领域层依赖能力接口，云适配器负责翻译 SDK 原生输入、输出和错误；不得要求云实现继承或伪装内存仓库。契约测试使用目标 SDK 的真实调用形状做桩，至少断言调用序列、条件表达式、分页、错误映射和事务边界。

## 高风险写入

| 写入类型 | 存储不变量 | 重试结果 |
| --- | --- | --- |
| 一次性领取/兑换/扣减/发货 | 条件更新、唯一约束或事务在存储层阻止第二次生效 | 返回未执行或明确冲突 |
| 创建型幂等 | 幂等键、请求摘要，并持久化首次成功结果 | 同键同载荷返回原结果；同键不同载荷冲突 |
| 多作用域私有读写 | 作用域由服务端会话与成员关系确定，并进入每个存储查询 | 错误作用域返回通用不可见/无权结果 |

客户端字段不能指定私有写入作用域。路由层鉴权不能替代存储查询中的作用域条件。随机会话令牌、API Key、恢复码等完整秘密只在必要创建时返回一次；持久化只保存不可逆摘要，日志、文档和测试快照不记录完整值或摘要值。

## 外部服务有效结果事务

外部评分、识别、OCR、支付、广告、上传等服务按四层判断：请求到达、服务返回、结果通过业务有效性校验、产品状态或计费提交成功。传输成功不等于业务结果有效。

一次用户提交应由一个锁定事务或等价状态机承接。只有有效结果才可写完成态、扣次数或费用；空结果、全零结果、缺字段、业务拒绝、超时或持久化失败都不得扣减，并保留可重试入口。供应商调用量与用户权益次数分开建模。

## 最小验证矩阵

- 权威状态：新用户、老用户、清缓存、换设备、重复创建、离线后收敛。
- 配置：整组缺失、部分缺失、双 provider、真实依赖不可达。
- 写入：并发第二次、同键同载荷、同键异载荷、错误作用域、列表隔离、令牌撤销/过期。
- 外部服务：有效、空/畸形、业务拒绝、超时、重复点击、结果晚到、服务成功但本地提交失败。
