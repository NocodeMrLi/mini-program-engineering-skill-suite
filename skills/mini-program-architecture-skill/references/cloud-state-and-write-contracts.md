# 云端状态、配置与写入安全合同

仅在项目涉及云端权威数据、持久化、第三方 SDK、多租户、一次性权益或外部计费服务时应用本合同；未触发的部分标记不适用，不为补表创造能力。

## 权威数据三态与恢复

- `unresolved`：尚未从可信缓存或权威源完成解析，不能展示“确认无数据”的流程。
- `confirmed-existing`：权威记录存在，进入正常路径并刷新可重建缓存。
- `confirmed-absent`：权威源明确确认不存在，才允许首次创建、领用或初始化。

本地无记录不等于云端不存在。创建返回“已存在/重复”时读取并采用持久化赢家结果，恢复缓存和正常路由。离线兜底必须有回写或对账路径，云端恢复后收敛到主数据。

## 配置组与真实依赖

- 对每组可选云能力列出必需变量、互斥 provider、默认禁用行为和校验时点。
- 整组缺失可以按已确认的未启用路径降级；只提供部分变量必须 fail-closed 并列出缺项。
- `.env.example` 只保留变量名和安全占位符，不放真实资源 ID、账号、地址或秘密。
- 导入目标、迁移集合/表、运行时依赖注入和 health 探测从同一配置源解析。
- health 分开报告进程存活与数据库、存储、队列等真实依赖可用性。

## 适配器边界与契约测试

领域层依赖能力接口，云适配器负责翻译 SDK 原生输入、输出和错误；不得要求云实现继承或伪装内存仓库。契约测试使用目标 SDK 的真实调用形状做桩，至少断言调用序列、条件表达式、分页、错误映射和事务边界。

## 高风险写入

| 写入类型 | 存储不变量 | 重试结果 |
| --- | --- | --- |
| 一次性领取/兑换/扣减/发货 | 条件更新、唯一约束或事务在存储层阻止第二次生效 | 返回未执行或明确冲突 |
| 创建型幂等 | 幂等键、请求摘要，并持久化首次成功结果 | 同键同载荷返回原结果；同键不同载荷冲突 |
| 多作用域私有读写 | 作用域由服务端会话与成员关系确定，并进入每个存储查询 | 错误作用域返回通用不可见/无权结果 |

客户端字段不能指定私有写入作用域。路由层鉴权不能替代存储查询中的作用域条件。随机会话令牌、API Key、恢复码等完整秘密只在必要创建时返回一次；持久化只保存不可逆摘要，日志、文档和测试快照不记录完整值或摘要值。

## 外部服务有效结果事务

外部评分、识别、OCR、支付、广告、上传等服务按四层判断：请求到达、服务返回、结果通过业务有效性校验、产品状态或计费提交成功。传输成功不等于业务结果有效。

一次用户提交应由一个锁定事务或等价状态机承接。只有有效结果才可写完成态、扣次数或费用；空结果、全零结果、缺字段、业务拒绝、超时或持久化失败都不得扣减，并保留可重试入口。供应商调用量与用户权益次数分开建模。

## 最小验证矩阵

- 权威状态：新用户、老用户、清缓存、换设备、重复创建、离线后收敛。
- 配置：整组缺失、部分缺失、双 provider、真实依赖不可达。
- 写入：并发第二次、同键同载荷、同键异载荷、错误作用域、列表隔离、令牌撤销/过期。
- 外部服务：有效、空/畸形、业务拒绝、超时、重复点击、结果晚到、服务成功但本地提交失败。

## 本地履约与外部确认

本地事务完成与平台/供应商确认是两个状态源。在本地提交事务中原子保存待确认意图、原业务键及恢复信息；外部调用放在事务外。恢复查询与物理索引必须覆盖“本地已完成、外部未确认”，不能只扫未支付或未到账记录。重试复用原业务，不再次发权益或扣库存；按供应商幂等/查单合同处理未知响应。

并发领取、进程中断、租约与晚到结果要按项目合同处理，旧尝试不能覆盖新尝试。有界耗尽进入可发现的人工复核并告警，不能写外部成功。关闭新增业务保留允许的查单、履约、补偿和核账。无业务且确认无在途时才考虑完整基线回退；已受理/结果未知时禁止套回会关闭恢复能力的旧配置，可信终态后才按合同关闭新增任务。

最小反例：本地提交后崩溃、通知拒绝/丢响应、重复扫描/回调、晚到、耗尽及三种回退时点。分别断言本地不变量、待确认可发现、善后可运行及对应证据层；模拟通知不是平台确认。

## 唯一约束的完整生命周期

为每个阶段列文档角色、基数、唯一键、关联键及事务边界。测试桩执行目标库唯一约束语义，覆盖任务到结果的第二次写入、重复结果、并发赢家及关联事务失败。分集合、角色复合键或单记录演进均可，不为测试通过删除唯一约束。

若做隔离库探针，先授权、有界并记录精确清理，读回字段、顺序、方向和唯一性。重复写被拒绝只证明该索引，不证明任务/结果完整生命周期通过。

## 业务控制不依赖诊断

仅在已有权威暂停、权限、额度或风险控制时启用。在最终事务或等价原子写入边界独立检查权威控制，诊断、日志、告警关闭不能跳过保护。控制读取失败/损坏按已确认拒绝策略处理；结案与解除限制分别建模。恢复请求核权限及预期版本，过期请求不能覆盖新控制；重复合法恢复按幂等合同处理。

验证暂停且诊断关闭仍零新增写入，覆盖控制损坏/不可读、无权/过期恢复、结案仍暂停、合法及重复恢复；允许的存量善后另核。不强加来源项目的等级、字段或冻结系统。

## 签名载荷的传输合同

先定义签名绑定原始字节/字符串还是协议规定的结构化值，列发送端、SDK、网关与接收端的解析/重编码边界。原文协议保留同一原文，不排序第三方要求的原文；仅自有或明确允许规范化的协议可双方约定完整字段、键序、数组次序、类型、缺失值及编码规则。不能忽略业务字段或放宽验签求兼容。

测试经过独立重序列化适配器，不让双方共用同一辅助函数自证。允许的对象键重排不误拒绝；嵌套篡改、字段增删、类型改变及有序数组换序均拒绝，非法载荷零业务写入。实际通道行为如需确认，另做授权、有界、无业务副作用探针。

## 仍在线的客户端与共享后端

列线上旧版、新候选、提审版与后端合同的组合，逐组合核请求字段、响应、幂等结果与恢复语义，纳入平台审核时间差。非兼容变更选择有依据的兼容适配、版本接口或维护/发布顺序；不规定统一先端后云或先云后端。

缺身份或幂等字段不能由服务端随机补键、放宽身份或自动重放掩盖。回退核端云组合和在途任务不变量，必要时最小前向修复。候选单样本不证明现网恢复，未执行组合保持未核。发布阶段按 [云发布合同](../../mini-program-release-skill/references/cloud-release-operations.md) 记录矩阵。
