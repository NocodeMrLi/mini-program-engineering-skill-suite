# 云端发布与发布后运维门禁

本门禁只在项目包含云函数、云托管、外部后端、数据库、对象存储、依赖审计或分享/公开入口时启用；每一类外部动作仍需单独授权。

## 部署前 Preflight

报告当前 commit、目标环境、配置组完整性、互斥 provider、迁移/导入文件、生产依赖、平台前提和回滚目标。`error` 阻断部署，`warning` 必须有影响和责任边界；不得为了继续发布把 error 改名为 warning。

生产后端至少提供彼此独立的 production build、production start 和 smoke 证据。开发运行器、类型检查或容器构建成功不能替代生产启动；只证明进程存活的 health 不能替代数据库、存储等真实依赖探测。

## 依赖审计

记录审计工具、registry/漏洞源、退出状态、严重度和依赖路径。镜像无审计端点、网络失败或鉴权失败只能标记 `not-verified`；改用受信漏洞源复核。高危可达问题阻断真实部署；修复不得默认使用强制跨主版本升级，变更后重跑类型检查、全量测试、构建、生产 smoke 和审计。

## 分享与公开入口

存在分享、深链或公开入口时，核对标题、素材、目标路径、权限和公开安全落地页。个人进度、订单、管理、结果或调试页面不能因入口可触发就默认适合作为外部落地页。

## 发布后云环境交接

发布前记录：

| 项目 | 必填内容 |
| --- | --- |
| 环境身份 | 脱敏环境标识、用途、创建/管理账号角色 |
| 生命周期 | 到期或续费节点、负责人、提醒提前量 |
| 成本 | 预算上限、当前用量来源、升级原则 |
| 监控 | 日志、错误、调用、数据库、存储/CDN 和费用入口 |
| 处置 | 告警负责人、降级/回滚条件、复验步骤 |

不固化供应商价格或活动规则；每次续费以当前控制台和官方资料为准。提交审核不等于运维交接完成，运维交接也不证明已正式发布。

## 端云发布组合与存量善后

线上旧版、新候选、提审版可能同时连接共享后端。记录实际线上版本/发布时间及后端合同，按组合核必需字段、可信身份、幂等、异步结果与恢复行为，纳入审核延迟。日志证明拒绝不能在缺原载荷时宣布唯一根因。选择兼容适配、版本接口或有依据的维护/部署顺序，不强制统一顺序。

| 客户端版本/渠道 | 后端合同/版本 | 请求/响应 | 恢复与在途不变量 | 实测/未核 | 发布/回退条件 |
| --- | --- | --- | --- | --- | --- |
| 旧正式/新候选/提审分别列 | 当前/候选/回退分别列 | 必需字段及错误语义 | 同原业务键、不重复扣额 | 单组合证据或 unknown | 维护窗口与审核时间差 |

不能为兼容随机补幂等键、放宽身份或盲重放。无业务且无在途时完整基线可作为回退候选；业务已受理/资金权益未知/外部未确认时先关新增入口，保留查单、履约、补偿、核账，禁止整包套回会关闭善后的旧开关。可信终态后才按合同停新增恢复任务。客户端或后端单独回退未必恢复，组合不安全时评估最小前向修复。

## 资源测算与用户交付

缺可靠用量时只给情景区间，记录基线污染、成本单位、失效条件、可逆资源策略和实际用量复盘阈值；不能把测算写成精确年度预测或采购门通过。预付费、长期承诺仍需新鲜数据及独立资金决定。

材料按用户指定位置与已有正式记录交付，核当前有效稿、同源附件、替代关系和可访问性，不追加无必要桌面副本。简单原生步骤准备好对象/动作/预期结果/失败回报，用户手动选择不能由助手接管 GUI；未知外部结果不换工具重放。按 [工具与分工](../../mini-program-project-intake-skill/references/intake-workflow.md) 比较用户负担及调用成本。
